Fit4Us V1.18.0 – Daily Crew Feed
===================================
DIESE VERSION HAT EINE DATENBANK-MIGRATION:
MIGRATION_V1_18_0.sql genau EINMAL im Supabase SQL Editor ausführen.

NEU: DAILY CREW FEED
- Ein Feedblock pro Person und Kalendertag statt eines Blocks pro Einzelereignis.
- Der Tagesblock wird über Realtime aktualisiert, sobald am Tag etwas hinzukommt/gelöscht/geändert wird.
- Aktivitäten, Schritte, Ernährung, Tageschallenge, Wochen-/Crew-Challenge,
  Achievements und Streak-Meilensteine werden in einem Tagesblock zusammengefasst.
- Tagespunkte und Streak stehen kompakt im Kopf.
- Maximal 4 Zeilen direkt sichtbar; weitere Inhalte lassen sich aufklappen.
- Mehrere Tagesfotos werden als kompakte Galerie angezeigt.
- Rückwirkende V1.17-Einträge landen im korrekten vergangenen Tagesblock.
- Crew Feed lädt 8 Tagesblöcke pro Seite, Home zeigt die 3 neuesten Tagesblöcke.
- Bestehende Reaktionen und Kommentare werden in den passenden Tagesblock übernommen.
- Neue Reaktionen/Kommentare beziehen sich auf den ganzen Personentag.

HOME
- Neuer Bereich „Was fehlt noch?“
- Zeigt nächsten Schritt-Punkt, offene Ernährungsziele, Tageschallenge und Streak-Status.
- Direkte Sprünge zur passenden Eingabe.

LAYOUT
- Streak-Darstellung im Feed vollständig neu und nicht mehr angeschnitten.
- Card-/Box-Abstände systematisch vereinheitlicht.
- Mobile/Tablet/Desktop Layouts für neue Feedkarten optimiert.
- Dark Mode für neue Karten mitgepflegt.

ANDROID / IOS PUSH
- Push bleibt plattformneutral über Service Worker + PushManager + VAPID.
- Profil zeigt jetzt eine Geräte-Diagnose:
  Gerät, Browser, Berechtigung, Service Worker, Push-Abo und WebApp-Status.
- Android wird explizit erkannt.
- Wenn auf Android alle technischen Punkte grün sind, ist Web Push registriert;
  der Test-Push bestätigt die tatsächliche Zustellung auf dem Gerät.

DATENSCHUTZ / DATENERHALT
- Keine bestehenden Entries, Challenges oder aktiven Zuordnungen werden verändert.
- Alte Einzel-Reaktionen/-Kommentare bleiben erhalten; eine Kopie wird dem neuen Tagesblock zugeordnet.
